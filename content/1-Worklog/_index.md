**Week 2:** [Amazon VPC, Subnets, Route Tables, and Network Security](1.2-week2/)

**Week 3:** [Amazon EC2, Amazon S3, and Amazon RDS Fundamentals](1.3-week3/)

**Week 4:** [Auto Scaling, Elastic Load Balancing, and Amazon CloudWatch](1.4-week4/)

**Week 5:** [Amazon CloudFront, Caching, Monitoring, and Content Distribution](1.5-week5/)

**Week 6:** [Serverless Architecture with AWS Lambda, API Gateway, SQS, and SNS](1.6-week6/)

**Week 7:** [Containers, Data Services, and AWS Deployment Technologies](1.7-week7/)

**Week 8:** [NightFury Express Requirements Analysis and Use Case Design](1.8-week8/)

**Week 9:** [AWS Architecture Design for NightFury Express](1.9-week9/)

**Week 10:** [Database, ERD, and User Interface Design](1.10-week10/)

**Week 11:** [Feature Completion, AWS Integration, and Software Testing](1.11-week11/)

**Week 12:** [AWS Deployment, System Validation, and Workshop Completion](1.12-week12/)
